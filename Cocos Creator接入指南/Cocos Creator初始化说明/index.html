Cocos Creator初始化说明

初始化说明

Note: 如果使用的是TopOn CocosCreator V1.1.1版本的话，则参考迁移文档：https://help.toponad.net/cn/docs/Cocos-SDK-API-qian-yi-zhi-nan

如果项目已支持topon的话，则可跳转到第4步。

1.可以通过以下代码初始化toponsdk： 

								
									//JS导入AnyThink SDK 
									require("./AnyThinkAds/ATJSSDK");
									var customMap = { "appCustomKey1": "appCustomValue1", "appCustomKey2"
									: "appCustomValue2" 
									}; 
									//设置自定义的Map信息，可匹配后台配置的广告商顺序的列表（App纬度）（可选配置）
									ATJSSDK.initCustomMap(customMap);
									var customPlacementId = "";
									if (cc.sys.os === cc.sys.OS_IOS) {
										customPlacementId = "b5b72b21184aa8";
									} else if (cc.sys.os === cc.sys.OS_ANDROID) {
										customPlacementId = "b5b449fb3d89d7";
									} 
									var placementCustomMap = { 
										"placementCustomKey1": "placementCustomValue1",
										"placementCustomKey2" : "placementCustomValue2" 
									};
									//设置自定义的Map信息，可匹配后台配置的广告商顺序的列表（Placement纬度）（可选配置）
									ATJSSDK.setPlacementCustomMap(customPlacementId, placementCustomMap); 
									// 设置GDPR的等级： 
									// ATJSSDK.PERSONALIZED（允许上报个人信息） 
									//ATJSSDK.NONPERSONALIZED（不允许上报个人信息） 
									// ATJSSDK.setGDPRLevel(ATJSSDK.PERSONALIZED);
									// 获取GDPR等级 
									var GDPRLevel = ATJSSDK.getGDPRLevel(); 
									// 初始化SDK 
									ATJSSDK.initSDK("appid", "appkey");
									// 针对欧盟地区初始化时做的处理，按需求打开，不在欧盟地区发布的不用使用。 
									ATJSSDK.getUserLocation(function (userLocation) { 
										//如果处于欧盟地区且等级是UNKNOW时，就执行授权弹窗 
										if (userLocation === ATJSSDK.kATUserLocationInEU){ 
											if(ATJSSDK.getGDPRLevel() === ATJSSDK.UNKNOWN) {
												ATJSSDK.showGDPRAuth();
											} 
										} 
									});

2.使用SDK加载和展示广告前，需要调用initSDK方法

3.通过setDebugLog方法，可以开启调试日志，方便定位SDK集成中遇到的问题

4.在需要展示插屏广告和激励广告的场景内添加返回按键处理，参考下面代码： 

								
									extends: cc.Component, onLoad() { 
										// 监听按键事件 
										cc.systemEvent.on(cc.SystemEvent.EventType.KEY_DOWN, this.onKeyDown, this); 
									}, onKeyDown(event) { 
									if (event.keyCode === cc.macro.KEY.back)
									{ 
										if(mShowing){ 
										//此处需要添加发送广播的行为，广播的action分别为："com.adflow.adflowsdk.interstitial.back"，"com.adflow.adflowsdk.reward.back"
											event.preventDefault(); 
										// 阻止默认行为 
										} console.log("返回键被按下，但已被屏蔽");
										// 你可以在这里添加自定义逻辑，比如弹出退出确认对话框 
									} 
									}, onDestroy() { 
										// 移除事件监听 
										cc.systemEvent.off(cc.SystemEvent.EventType.KEY_DOWN, this.onKeyDown, this); 
									}

此处的mShowing是判断当前正在展示广告，展示广告期间，屏蔽返回按键，避免返回操作直接关闭当前正在展示的广告。可以在该场景内监听函数内的onInterstitialAdShow/onRewardedVideoAdPlayStart接口内设置mShowing为true，在onInterstitialAdClose/onRewardedVideoAdClosed接口内设置mShowing为false。详情请查看激励视频广告/插屏广告
