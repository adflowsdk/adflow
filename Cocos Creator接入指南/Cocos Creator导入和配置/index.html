    Cocos Creator导入和配置

    Cocos Creator接入指南

    如果项目已经支持topon则可跳转到第4步骤

    导入和配置

    1. 将TopOnSDK添加到您的项目内

    2. 如果有topon账号的话，可以访问https://portal.toponad.com/m/sdk/download?type=CocosCreator，选择最新的SDK版本，并点击下载按钮最新版本的sdk。如果没有topon账号的话，可以联系客服或者技术支持索要类似：https://sdk-release.toponad.com/cocoscreator/1.1.0/TopOn_CocosCreator_SDK_v1.1.0_release.zip直接下载链接。注请下载最新版本。

    3. 在SDK的压缩包里选择Android平台下的anythink_cocosjs_bridge.aar包放到项目工程libs目录下，并通过build.gradle进行引入

    dependencies { api fileTree(include: ['*.jar','*.aar'], dir: 'libs') }

    1. 引入所有需要支持的广告平台。

    2. 如果有topon账号的话，请到TopOn官网下载页面, 勾选需要集成的平台，点击生成接入代码。最后按照生成的Gradle引用代码和AndroidManifest.xml代码添加到自己项目对应文件内。

    3. 如果没有topon账号的话，请联系客服或者技术支持，并告知自己需要引入的所有广告平台的名字，之后将给回的配置添加到项目的对应文件内

    4. 添加如下配置到build.gradle

      implementation("com.squareup.okhttp3:okhttp:4.12.0")

    5. 把我们的adflowads-release.aar复制到libs文件夹内
